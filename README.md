⚠️ البنود والالتزامات الشاملة وبراءة الذمة (مُغلقة لكافة الثغرات):
المطالبة بالحذف والإزالة الفورية: أطالب كل شخص قام بتحميل، أو تثبيت، أو نقل، أو حفظ أي ملف أو تعريب صادر عني سابقاً، بأن يتقي الله ويقوم بحذفه وإزالته نهائياً من جهازه أو وسائط تخزينه فوراً.

المنع المطلق لإعادة النشر والتداول: يُحظر حظراً تاماً وبأي شكل من الأشكال إعادة رفع، أو نشر، أو تداول، أو إتاحة أي ملف من ملفات تعريباتي (سواء كانت كاملة أو جزئية) على أي موقع، أو منصة، أو قناة تيليجرام، أو سيرفر ديسكورد، أو منتدى، أو شبكات التورنت، أو مراكز التحميل السحابية.

حظر التعديل، الاقتباس، والهندسة العكسية: يُحظر تماماً على أي فرد أو جهة تعديل، أو فك ضغط، أو استخراج، أو دمج، أو اقتباس النصوص والملفات والأكواد التي قمت بتعريبها أو تطويرها، أو بناء أي عمل آخر عليها، أو الادعاء باستكمال المشروعات من بعدي.

المنع التام للبيع والتجارة والتربح: يُحظر حظراً جازماً استخدام أي جزء من هذه الملفات لأغراض تجارية، أو بيعها، أو شرائها، أو وضعها خلف روابط ربحية أو إعلانية، أو استغلالها المالي بأي صورة من الصور المباشرة أو غير المباشرة.

حظر نقل الملكية أو نسَب العمل للغير: يُحظر على أي شخص أو جهة نسب هذه الأعمال لنفسه أو ادعاء ملكيتها أو إعادة إعادة إنتاجها تحت أي مسمى آخر.

إسقاط الحقوق وعدم المسامحة الشرعية: لا أُبيح، ولا أُحلل، ولا أسامح أحداً—كائناً من كان—يتجاهل هذا التنبيه، أو يستمر في استخدام، أو نشر، أو بيع، أو تعديل، أو تداول، أو الاحتفاظ بهذه التعريبات، لا في الدنيا ولا في الآخرة، وأبرأ إلى الله تعالى من فعل أي شخص يخالف هذا البيان بعد صدوره.
